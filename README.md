## 内容与检查方法

- 109 个手机页面和页面状态，包括登录、首页、分类、搜索、商详、购物车、结算、银行卡、订单、评价、地址、账户、积分、客服。
- 三种定制商卡和两个分类框架已纳入业务库；旧 26 个商卡入口下架，历史文件保存在 `work/retired-product-cards/`。
- 原稿模式：用于逐页视觉对照，不连接业务接口。
- 交互演示：覆盖登录、商卡购买与规格选择、分类切换及其他页面的本地交互。不会发送短信或提交真实订单，业务接口需由应用接入。
- 侧栏支持按名称、模块和节点 ID 搜索；顶部可缩放并打开对应 Figma 节点。
- “基础样式”展示初步观察值；“待确认与计划”集中列出设计冲突及后续步骤。

建议先检查登录、首页、分类、商详、购物车、结算等典型页面的字体、间距、图片裁切和长页面，再逐项检查状态差异。公共组件与规范见 [DESIGN-SYSTEM.md](./DESIGN-SYSTEM.md)，具体差异见组合页审核标注。

## 项目结构

- `src/screens/`：React 页面与子区域，保留 `data-node-id` 便于追溯。
- `src/manifest.json`：完整页面清单、尺寸、模块与 Figma 来源链接。
- `src/figma.css`：由设计上下文转换的普通 CSS；未引入 Tailwind。
- `src/prototype.tsx`、`src/prototype.css`：登录与授权本地交互演示。
- `src/tokens.css`：初步基础值与 DdmcSans 字体声明，尚非最终变量体系。
- `src/source-notes.json`：原稿中的商品卡片规则和说明。
- `src/main.tsx`、`src/review.css`：验收网站导航与预览界面。
- `public/assets/`：584 个从 Figma 保存的原始素材，另有 4 个原稿键盘图标导出。运行时不使用临时 Figma 图片地址。
- `public/fonts/`：从本机原有字体安装目录接入的 DdmcSans；Poppins、Leckerli One 由本地依赖打包。
